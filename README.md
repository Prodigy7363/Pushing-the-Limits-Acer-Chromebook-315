# Pushing the Limits: Acer Chromebook 315

This is my project for seeing how far I can push an Acer Chromebook 315 with pretty limited hardware. It has an Intel Celeron N4500, Intel UHD integrated graphics, and 4 GB of RAM. It is not a powerful machine, which is exactly why I wanted to experiment with it.

The goal is to get as much out of it as I reasonably can, learn more about Linux in the process, and keep notes on what works, what causes problems, and what is worth trying next. I may change Linux distributions or desktop environments later, so this project is about the Chromebook and the experiments, not just one operating system.

## Current setup

- **Device:** Acer Chromebook 315, model family CB315-4H/4HT
- **Board:** MAGMA / magma-rev6
- **CPU:** Intel Celeron N4500, 2 cores
- **Graphics:** Intel UHD integrated graphics
- **Memory:** 4 GB RAM
- **Storage:** eMMC storage, approximately 114 GB available to the Linux installation
- **Current operating system:** Linux Mint
- **Desktop environment/window manager:** i3
- **Display:** 1920 × 1080

These details describe the setup I have been working with. The exact installation steps and configuration may change as I keep experimenting.

## What I am working on

- Getting Linux running on the Chromebook
- Customizing i3 and building a desktop that is comfortable to use
- Setting up Polybar, Rofi, Kitty, Picom, wallpapers, and hot-pink accents
- Troubleshooting audio, power-button behavior, screenshots, and desktop layout
- Keeping memory use under control on a 4 GB system
- Testing what the hardware can handle and documenting its limits
- Trying different tools or Linux setups over time

## Why I am doing this

I want to see how usable I can make a low-spec machine instead of writing it off because the hardware is limited. Some experiments will work better than others. I want to document the real results, including the annoying parts, so I can learn from them and hopefully help someone else trying something similar.

This is a work in progress. It is not meant to be a one-click installer or a claim that every part of the setup will work on every Chromebook.
